# InstaStock 智能零售进销存与分货辅助系统

> 个人主页与实战作品集 · 张晨宇 (AI 产品经理)

---

## 📌 项目背景
本系统针对数码消费电子线下多门店协同中“录单繁琐、实际成交价与官方标价对账混乱、月度店员销售额统计耗时耗力”等痛点，自研设计的纯前端进销存与辅助工具。系统支持实收成交价自动登记、跨店平调记录，并能一键按月度汇总店员个人销售业绩与提成。

## 🚀 核心功能
1. **智能报单解析**：自动解析口语文字，智能提取实收销售价格与经办销售署名，结合影石专有品名字典库进行前置纠偏；
2. **实收价格与折扣记录**：严格区分官方指导价与实收成交价，自动核算让利差价，与微信/POS机收款分毫不差；
3. **安全边界断言**：读写分离原则，模型仅解析语义，库存不足立即拦截熔断，杜绝负库存记账；
4. **日结单与月度业绩汇总**：一键生成日销售单防乱填，支持按月自动核算各店员总销售额、出货台数与提成排名。

## 💻 本地运行
直接在浏览器中打开 `index.html` 即可完整体验，无需安装任何依赖或启动后端服务器。
